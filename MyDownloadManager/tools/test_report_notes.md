## Scope

- **C# suite** (`tests/MyDownloadManager.Tests`, xUnit): unit tests plus integration tests against an in-process
  Kestrel HTTP server serving test data generated by the tests themselves. Every download test compares the SHA-256 of
  the downloaded file with the source. Media tests generate their own H.264/AAC, VP9/Opus, HLS (TS, fMP4, AES-128)
  and DASH content with FFmpeg and validate results with ffprobe. Includes a 4 GB+ multi-connection download.
- **Browser extension suite** (`extensions/test`, `node --test`): 8 tests for interception rules, media
  classification, de-duplication, message building and manifest consistency — 8/8 passing.
- **Windows-only checks** run in the GitHub Actions `windows-latest` job (`.github/workflows/mydownloadmanager.yml`):
  the full C# suite on Windows, a smoke test of the real WPF app (window renders, IPC ping, 48 MB download with hash and
  Mark-of-the-Web check, screenshot), installer compilation, silent install, registry/native-host verification,
  native-host ping, and uninstall clean-up. Its report is uploaded as `test-results-windows/TEST_REPORT_windows.md`.
