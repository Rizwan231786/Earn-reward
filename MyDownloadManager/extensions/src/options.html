MyDownloadManager browser integration

Troubleshooting

  • “Native host unavailable”: MyDownloadManager is not installed, or the browser integration was not registered. Open MyDownloadManager → Settings → Browser integration → Repair, then restart the browser.
  • Installed the extension from a store or a different folder? Its ID must be listed in the native host manifest. Expected IDs: Chrome/Edge jepeaacjobbkicoofllleimejjcjebge, Firefox mydownloadmanager@mydownloadmanager.app.
  • Firefox: grant “Access your data for all websites” in about:addons → MyDownloadManager → Permissions, otherwise videos cannot be detected and cookies cannot be forwarded.
  • No “Download This Video” button: start playback first. Streams protected with DRM (Widevine, PlayReady, FairPlay) are shown as “Protected” and cannot be downloaded — this is intentional.
  • Download fails with 403: the site requires a signed-in session that is not available outside the browser, or the link expired. Start the download again from the page.
